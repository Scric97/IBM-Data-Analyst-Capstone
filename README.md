📊 **IBM Data Analyst Capstone Project: Developer Tech Trends & Market Insights**

An end-to-end data analysis project conducted on global software developer survey data to uncover emerging programming languages, database preferences, salary benchmarks, and demographic trends.

This project represents the final Capstone for the **IBM Data Analyst Professional Certificate** on Coursera.

---

🎯 Business Problem & Objectives
The technology landscape evolves rapidly, making it crucial for organizations, recruiters, and developers to understand current tech adoption and market compensation trends.

**Key Objectives:**
- Identify top in-demand programming languages, databases, and web frameworks.
- Analyze compensation distribution across age groups and experience levels.
- Evaluate developer demographics, education levels, and remote work preferences.
- Present actionable insights and interactive visual dashboards for decision-makers.

---

🛠️ Tech Stack & Methodology
- **Data Collection & Scraping:** Python (`requests`, `BeautifulSoup`), REST APIs, SQLite
- **Data Wrangling & Cleaning:** Python (`pandas`, `numpy`)
- **Exploratory Data Analysis (EDA):** Statistical summary, outlier detection, correlation analysis
- **Data Visualization & Dashboards:** `matplotlib`, `seaborn`, Cognos / Looker Studio dashboards
- **Reporting:** Executive summary slides and comprehensive PDF report
